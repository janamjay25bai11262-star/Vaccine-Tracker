 Project Title
Super Simple Vaccination Tracker

Overview of the Project
The Super Simple Vaccination Tracker is a beginner-friendly Python program designed to help users add vaccines, record due dates, mark them as given, and view a summary. It uses basic input prompts and simple data structures, making it easy to understand and suitable for beginners learning Python.

Features
Add multiple vaccines
Enter due dates for each vaccine
Mark vaccines as given or not
Display a clean summary of all vaccine records
Works entirely in the terminal
Easy to modify and expand

Technologies / Tools Used
Python 3
Basic data structures (lists and dictionaries)
Terminal/command-line interface

Provide its due date.
