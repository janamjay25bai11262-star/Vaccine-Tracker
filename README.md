Project Title

Vaccination Tracker

Overview of the Project

The Vaccination Tracker is a simple Python-based application that helps store and manage vaccination records of individuals. It allows users to add personal details, update vaccine doses, and view all saved records. This project is designed to demonstrate basic data handling and menu-driven programming.

Features

Add new vaccination records

Update dose 1 or dose 2 status

Display all stored vaccination details

Easy-to-use menu-driven interface

Technologies/Tools Used

Python programming language

Basic data structures (lists & dictionaries)

Command-line interface (CLI)
